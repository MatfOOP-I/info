# Информације које се односе на вежбе


**16.11.2026. – Померање термина вежби за групе 2и1ц и 2и2а**

У уторак, 17.11.2026. године, вежбе за групе 2и1ц и 2и2а неће бити одржане. Надокнада вежби одржаће се према следећем распореду:
- **Група 2и2а:** среда, 18.11.2026. године, од 19:15 до 21:00, учионица 704.
- **Група 2и1ц:** четвртак, 19.11.2026. године, од 18:15 до 20:00, учионица Н201.
