# Информације које се односе на часове предавања уживо


## Часови предавања уживо

Часови предавања се у овој школској години реализују преко система [Webex](https://www.webex.com/).

Термини за реализацију часова су дефинисани на веб странама [Математичког факултета](http://www.math.rs/) у секцијама сајта који се односе на распоред наставе и на календар активности.
